# UWRGBD1k: a large-scale visible and depth dataset of underwater object tracking

This work releases a new RGB and depth (RGBD) dataset of underwater objects named UWRGBD1k for implementing  underwater object tracking. The UWRGBD1k is a large-scale dataset that consists of 1228 video sequences and collects total about 640 k frames. Compared with current RGBD dataset photographed on land, UWRGBD1k mainly focus on marine creatures and includes more than 26 types of marine creatures. Our resources will be available as soon as be accepted!
## Contributions:
1. This work releases a large-scale RGBD dataset of underwater object tracking named UWRGBD1k. UWRGBD1k includes 1223 video sequences that consists of 641.76 K frames and 15 challenging attributes.
2. This work proposes underwater RGBD tracking methods called UVDTrack. UVDTrack adopts a unsymmetrical constructure and the modality-crossing and time-crossing fusion strategy based on the correlated information.
3. This work conducts the comprehensive evaluation and comparsion of UVDTrack and other methods including single-modality/multi-modaltiy VOT methods on UWRGBD1k.
